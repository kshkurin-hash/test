# Игра «Шарики»

Игровое поле с анимированными шариками, которые смешивают цвета при касании.

## Как работает

- Шарики движутся по полю и отталкиваются от стен.
- При касании двух шариков их цвета **смешиваются через HSV-пространство** — как настоящие краски: красный + синий → фиолетовый.
- Повторный контакт тех же шариков не меняет цвет до тех пор, пока они не разошлись и не столкнулись снова.

**Управление:**

| Действие | Результат |
|---|---|
| ЛКМ на шарик | Всосать шарик в пул (панель слева) |
| ПКМ | Выпустить последний шарик из пула в позицию курсора |
| Перетащить шарик в зону «УДАЛИТЬ» (правый нижний угол) | Удалить шарик |
| Esc | Выйти |

Стартовое количество шариков задаётся константой `BALL_COUNT` в начале `gui.py`.

## Запуск локально

**Требования:** Python 3.10+

```bash
pip install pygame-ce
python gui.py
```

## Запуск в Docker

Контейнер запускает игру в графическом окне через X11.

### 1. Сборка образа

```bash
docker build -t ball-game .
```

### 2. Запуск

#### Windows (через VcXsrv)

1. Установи [VcXsrv](https://sourceforge.net/projects/vcxsrv/).
2. Запусти **XLaunch**:
   - Multiple windows → Display number: **0**
   - Start no client
   - Поставь галочку **Disable access control**
3. Запусти контейнер:

```bat
docker run --rm -e DISPLAY=host.docker.internal:0.0 ball-game
```

#### Linux / macOS

```bash
xhost +local:docker
docker run --rm \
  -e DISPLAY=$DISPLAY \
  -v /tmp/.X11-unix:/tmp/.X11-unix \
  ball-game
```
